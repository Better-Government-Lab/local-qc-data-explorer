Local QC Data Explorer

This application visualizes Quality Control (QC) errors in Supplemental Nutrition Assistance Program (SNAP) cases, based on a nationally representative sample reviewed by state and federal auditors. This tool uses SNAP Quality Control (QC) data, which is based on a sample of reviewed cases rather than the full population of SNAP participants. Differences across states may reflect variation in policy implementation and reporting practices, and should not be interpreted as direct comparisons of program performance. The data exclude cases found to be ineligible, which tend to represent larger errors. Users should interpret results with appropriate caution.

Preview. This is a browser-only version of the SNAP Quality Control Error Viewer. It runs entirely on your computer: the page makes no network connections, and a data file you load is never uploaded. Only the Error Pathways view is built so far.

Data Source: SNAP Quality Control Data. For the sankey diagram, nodes are ordered in descending frequency. A case is counted as an error when its total error amount is over the year's federal threshold. Dollar amounts are the case's total error amount, attributed to its first-listed error.
